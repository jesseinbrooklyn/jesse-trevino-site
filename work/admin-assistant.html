CRM workflow assistant

An AI assistant that does the routine admin of a design sales job (quotes, follow-ups, reminders, a daily plan) while I stay in charge of everything a client sees.

Role
Designed and built it
Status
Prototype, piloted on my own projects
Started as
A browser autofill extension

The problem

A design consultant spends a large share of the day on admin: building quotes line by line, logging every contact, setting and moving follow-up reminders, and checking order and install status across several screens. Each task is small. Together they eat the time that should go to clients.

What I built

It started as a browser extension that filled repetitive form fields for me. That helped, but it was fragile. So I rebuilt the idea as a prototype AI assistant that can look up a project, build and check a quote, set a reminder and read order status. The assistant does the routine steps; I decide what goes out.

How a day runs

  1. Morning briefing. Before I start, it reviews my follow-up queue and builds a one-page checklist: what's urgent, what's due, what's shipping. It only reads and drafts. It sends nothing.
  2. Working session. I work the list with the assistant: quotes, emails, reminders, calls. Items get checked off as they're done.
  3. Midday update. It compares the queue to the morning and reports only what changed.
  4. End-of-day check. It confirms every client touch that day was logged, so nothing goes unrecorded.

Guardrails

  • A person approves anything client-facing. Drafts are staged, never sent on their own.
  • Practice run by default. Actions that change a record show what they would do first, and only run when confirmed.
  • Quote checks. Every quote runs through 19 rules before it goes out, like size limits, expired promotions and zero-dollar lines. A failed check blocks the quote unless I override it with a written reason.
  • Read-only mode. One setting hides every action that could change anything, for sessions that should only look.
  • Written-down lessons. When the assistant gets something wrong, the mistake and the rule that prevents it go into its playbook with a date.
